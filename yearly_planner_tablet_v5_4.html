Using your planner

  • Use Quick add to create tasks, events, projects, goals, notes, budget allocations, transactions, accounts and loans.
  • Use Calendar for dated events and Tasks for actions you need to complete.
  • Planner records are stored in IndexedDB where supported. Export a backup before clearing browser data or changing devices. Budget allocations, transactions, accounts and loans are included. Loan repayments are calculated from their transaction history.
  • This is an offline-friendly single-file planner. New task and project entries wait for storage migration to finish before saving. It does not sync automatically between devices.
  • If embedded in Google Sites, keep using the same published embed URL, browser and device. Browser storage may be partitioned or restricted inside embedded pages. Export backups regularly; publishing a new URL or clearing site data may make the old local records unavailable.
